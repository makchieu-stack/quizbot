# @wingsquizbot — квиз-бот для Telegram

Некоммерческий бот для групп в Telegram: вопросы «Что? Где? Когда?» и тема «Угадай фильм по актёрам».

## Что умеет

- `/quiz_start 10` — квиз из N вопросов, до 5 минут на вопрос; после правильного ответа сразу следующий. В квизе «все темы» вопросы о кино идут с 4-го (по одному на каждые 10).
- `/q` — один вопрос, `/answer` — ответ, `/top` — таблица лидеров.
- `/theme чгк|кино|все` — тема вопросов чата.
- `/offer on|off` — раз в день бот сам предлагает сыграть, в часы, когда в чате обычно играют.
- `/appeal` — апелляция: реплаем на ответ игрока; решает админ или 3 голоса.
- Ответ принимается реплаем на вопрос; проверка мягкая (регистр, ё/е, пунктуация, опечатки, формы слов).
- Две копии бота (на двух компьютерах) не мешают друг другу; память о заданных вопросах и очках общая (копия хранится в личке владельца в Telegram).

## Запуск

1. Получите токен у [@BotFather](https://t.me/BotFather).
2. Создайте рядом с ботом файл `.env`:
   ```
   BOT_TOKEN=ваш_токен
   OWNER_ID=ваш_telegram_id
   ```
3. Windows — `start_bot.bat`, macOS — `start_bot.command`, Linux — `./start_bot.sh`. Скрипт сам поставит Python и библиотеки.
4. Для темы «кино» один раз запустите `fetch_photos` (скачивает свободные фото актёров с Викисклада).

Подробная инструкция на русском — в `ИНСТРУКЦИЯ.txt`.

## Файлы

| Файл | Что это |
|---|---|
| `quiz_bot.py` | бот |
| `answer_check.py` | проверка ответов |
| `fetch_questions.py` | докачка вопросов с gotquestions.online (резерв — db.chgk.info) |
| `fetch_photos.py` | фото актёров с Викисклада |
| `update_bot.py` | обновление из скачанного архива (`update.command` / `update.bat`) |
| `questions_seed.json` | стартовая база вопросов ЧГК |
| `custom_movies.json` | вопросы «Угадай фильм по актёрам» |

Не публикуются (см. `.gitignore`): `.env` с токеном, `state.json` с очками и именами игроков, журнал, скачанные вопросы и фото.
